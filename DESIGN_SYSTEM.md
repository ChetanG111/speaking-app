# Design System: Premium Dark Analytics

This design system is extracted from the provided mobile analytics dashboard. It focuses on a high-end, dark-mode experience with vibrant orange accents.

## 🎨 Color Palette

| Category | Role | Hex / Value | Usage |
| :--- | :--- | :--- | :--- |
| **Background** | Core Backdrop | `#000000` | Main application background. |
| **Surface** | Card Surface | `#111111` | Primary container for metrics and content. |
| **Primary** | Accent | `#FF8800` | Calls to action, high-importance metrics, and active states. |
| **Secondary** | Highlight | `#FFAA00` | XP values and "Level Up" buttons. |
| **Border** | Subtle Edge | `#1E1E1E` | Card outlines and separators. |
| **Text - High** | Primary | `#FFFFFF` | Headlines and critical numeric metrics. |
| **Text - Med** | Labels | `#999999` | Descriptive labels and minor text. |
| **Text - Low** | Dimmed | `#555555` | Placeholders or disabled text. |

## 📐 Spacing & Layout

- **Border Radius**: Large, rounded corners (`24px` / `1.5rem`) for cards.
- **Padding**: Generous inner card padding (`1.5rem`).
- **Gap**: Standardized grid gap (`1rem`).

## 🔠 Typography

- **System**: Modern Sans-Serif (Recommended: `Inter` or `Geist`).
- **Font Sizes**:
    - **Jumbo**: `3.5rem` (Main metrics like score).
    - **Header**: `1.25rem` (Section titles).
    - **Base**: `1rem` (Standard reading).
    - **Small**: `0.875rem` (Labels/metadata).

## ✨ UI Components

### Cards
- **Background**: `#111111`
- **Border**: `1px solid #1E1E1E`
- **Radius**: `1.5rem`

### Buttons
- **Primary**: Solid orange with rounded corners.
- **Outline**: White/Grey border with centered text.

### Accents
- **Glow**: Subtle orange glow for progress bars or active indicators.
